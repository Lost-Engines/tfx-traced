# TFX Traced

[Visit TFX Traced](https://lost-engines.github.io/tfx-traced/)

A public introduction to the Lost Engines TFX investigation, with interactive
map and model viewers, cockpit artwork and a short synthesiser comparison.

[How TFX draws a world](https://lost-engines.github.io/tfx-traced/graphics/)
is an illustrated guide to the graphics engine, with interactive diagrams and
comparisons with Inferno.

[How TFX flies](https://lost-engines.github.io/tfx-traced/flight/)
explores the flight model, from lift and control laws to engines and landing gear.

[How TFX’s weapons work](https://lost-engines.github.io/tfx-traced/weapons/)
follows the missiles and bombs from release to impact, with original-code measurements
and comparisons with the handbook.

The full [research archive](https://lostengines.com/tfx/) is published separately.
See [maintaining the site](MAINTAINING.md) and [attribution](RIGHTS.md).
